# Vector Databases & Approximate Nearest Neighbor (ANN) Indexing

Vector databases index high-dimensional embeddings generated by neural networks to support semantic similarity search using distance metrics such as Cosine Similarity, Dot Product, or Euclidean (L2) Distance.

### Exact Search vs. ANN
Exact k-Nearest Neighbors (k-NN) computes distances across all $N$ vectors in $O(N \cdot d)$ time, which becomes prohibitively slow for millions of vectors. Production systems trade a tiny percentage of recall for orders of magnitude lower latency by using Approximate Nearest Neighbor (ANN) algorithms.

### HNSW (Hierarchical Navigable Small World)
HNSW builds a multi-layer graph where lower layers contain all points and upper layers contain long-range skip-connections (similar to a probabilistic skip-list). Greedy routing on upper layers quickly navigates toward the target vector neighborhood, and lower layers perform fine-grained exploration. HNSW offers the best trade-off between search latency and recall for real-time querying.

### Inverted File Index with Product Quantization (IVF-PQ)
IVF clusters the vector space into Voronoi cells via k-means. At query time, only vectors within the nearest centroids are inspected. Product Quantization (PQ) compresses vectors into small byte codes, reducing memory footprint by 80-95% at the expense of slight quantization error.
